# 我的通用原则

**这个文件是 agent 替你做判断的依据。** 一条一行。

写在这里的是**横跨所有板块**的原则；只影响某一个板块的，写进那个板块自己的 `principles.md`。

## 什么算一条好原则

- **可判定**：能回答「这条有没有被违反」。「保持健康」不行，「每周至少三次力量训练」行。
- **是约束，不是愿望**：愿望属于 `goals.md`。
- **写成 agent 能直接引用来拒绝你的样子**。越硬越好——它是给你踩刹车的，不是给你打气的。

## 谁可以写

人和 agent 都可以**提议**，但落盘必须经你确认。agent 不得自行修改本文件。

## 格式示例

```
- 任何决策不得以牺牲睡眠为代价：睡不满 7 小时的当天不做重大决定
- 不接低于 X 元的项目，无论当时多闲
- 涉及钱的承诺，先过一夜再答
```

_访谈结束后，这里会被填成你自己的内容。_
