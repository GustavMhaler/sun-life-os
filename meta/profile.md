# 我这个人

跨板块的、稳定的、几乎不变的**事实**。只有真正稳定的东西才写在这里；会变的东西属于各板块的 `state.md`。

## 装什么

- 基本盘：出生年、所在城市、家庭结构、职业身份
- 身体的硬事实：身高、基础病、长期用药、过敏
- 不可协商的约束：工作时间、家庭责任、地理限制
- **长期价值排序**：什么最重要——这条决定 agent 怎么替你权衡取舍

## 不装什么

会变的目标（→ `goals.md`）· 当前状态（→ `state.md`）· 偏好判据（→ `principles.md`）

## 谁可以写

**只有人能写。** agent 只读，任何时候都不要让它改这个文件。

**唯一的例外是访谈期**：包还没访谈过（根目录没有任何板块目录）且正在跑访谈流程时，agent 可以代录本人口述填进这里——落盘前必须把要写的内容整体复述并经本人确认，写入后在本文件末尾注明「由 agent 代录本人口述」。访谈一结束（板块目录已生成），这个例外立即失效，回到只读。依据见 `docs/adr/0015`。

## 格式示例

```
- 1990 年生 · 常住 <城市>
- 身高 <cm>，无基础病，乳糖不耐
- 价值排序：健康 > 家人 > 事业 > 收入
```

> 示例里的城市一律写成 `<城市>` 这样的占位符——**不要用真实地名**，避免和某个使用者的常住地巧合撞上。

_访谈结束后，这里会被填成你自己的内容。_

## 访谈期的三处约定

- **理论包选择**：选了哪几套可选理论包、什么时候选的，记在这个文件里（理论包机制见 `_skills/life-os/references/theories/adaptation.md`）。
- **待定区**：访谈中答不上来或被跳过的条目，统一放进本文件末尾的 `## 待定`，不要散落到各板块。
- **画像代录**：访谈期本文件由 agent 代录本人口述，落盘前必须整体复述并经本人确认，写入后在本文件末尾注明「由 agent 代录本人口述」（见上「谁可以写」与 `docs/adr/0015`）。
