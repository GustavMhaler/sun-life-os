# 目标（Goal）

**本文件装什么**：有**期限、可判定是否达成**的追求，例如「三个月内卧推到 80kg」。

**本文件不装什么**：稳定事实（画像）、硬约束判据（原则）、当前快照（状态）、流水记录都不在此。

**谁可以写**：人与 agent 都可写，但 agent 改目标须遵循写权限——默认只读，改动需经人确认或留下记录。目标会过期、会被替换。

格式示例：

- [ ] 例：2026-Q4 前，月度被动收入达到 5000 元
- [ ] 例：半年内完成一门数据分析课程
