# 五类记录模板与板块范围

`_template/` 放五类记录的空样板。访谈结束后，agent 为每个**激活**的板块各生成一套（五类，共五个文件）；生成时样式照这里。**访谈数据不写进本目录。**

## 一、五类记录（结构契约，实例不得增删类别）

| 文件 | 装什么 | 谁可以写 |
|---|---|---|
| `profile.md` | 稳定的、几乎不变的事实 | 只有人；**访谈期由 agent 代录**（见 `docs/adr/0015`） |
| `goals.md` | 有期限、可判定是否达成的追求 | 人确认后可改 |
| `principles.md` | 硬约束与偏好判据（最重要） | 人确认后可改 |
| `state.md` | 当前快照，反复被覆盖 | agent 可改，**必须留变更记录** |
| `log/YYYY-MM.md` | 追加式、写后不改的流水 | agent 唯一默认可写对象 |

依据 `docs/adr/0003`、`docs/adr/0009`。

## 二、八个板块各管到哪

下面八句是**唯一措辞**，逐字出现在 `_skills/life-os/references/domains.md`、`_skills/life-os/SKILL.md`、`CONTEXT.md`、本文件与包根 `README.md`：

- `body` **身体**：**身心硬件的状态与维护**——训练、摄入、睡眠、体征、伤病与恢复
- `mind` **心智**：**内在状态与自我认定**——情绪、压力、注意力、动力，以及你怎么看自己
- `career` **事业**：**你靠什么谋生，以及工作怎么组织**——职业身份与路径、工作协作、项目管理
- `knowledge` **学识**：**学习与真本事**——读什么、学什么、怎么把输入变成能用的能力
- `money` **财务**：**钱本身**——收入结构、支出、储蓄、投资纪律与财务安全线
- `relations` **关系**：**一切长期人际关系**——家人、伴侣、亲友、同事
- `life` **生活运营**：**日常怎么转起来**——日程、家务、通勤、物品与文件的打理、拖着没做的杂事
- `create` **创造**：**你产出的作品**——写作、视频、项目、博客、代码

## 三、归属唯一

同一件事只进一个板块；别的板块要用它，写相对路径引用指过去，不要抄进两处。边界重叠时的分流规则见 `_skills/life-os/references/domains.md`。
