# 画像（Profile）

**本文件装什么**：本板块内**稳定、几乎不变**的事实信息，例如身体板块的固定病史、事业板块的学历与职能定位。

**本文件不装什么**：会变化的状态、目标、原则、流水都不在此；它们各有专属文件。

**谁可以写**：**只有人能写**。agent 默认只读，禁止修改本文件。**唯一例外是访谈期**：包还没访谈过（根目录没有板块目录）且正在跑访谈流程时，agent 可代录本人口述——落盘前必须整体复述并经本人确认，写入后在本文件末尾注明「由 agent 代录本人口述」；访谈一结束（板块目录已生成）立即回到只读。依据见 `docs/adr/0015`。

格式示例：

- 例：乳糖不耐，喝奶后腹泻
- 例：2018 年毕业于 XX 大学，计算机专业
