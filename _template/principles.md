# 原则（Principle）

**本文件装什么**：**给 agent 做判断用的判据**。每一条都是一条可判定、不可模糊的硬约束或偏好，agent 在给建议时直接引用。

**本文件不装什么**：事实信息（画像）、目标（goals）、当前快照（状态）、流水都不在此。

**谁可以写**：人写为主；agent 可建议增补，但默认只读。

**写法硬要求**：一条一行；每条必须**可判定**——能明确判断「这条原则有没有被违反」。禁止写「尽量」「健康一点」这类无法判定、无法验伪的句子。

格式示例：

- 每周三次力量训练，缺一次即视为违反
- 不碰含乳糖的饮品
