## 它是什么

薄肌最初是一个身体目标：**有肌肉基础、线条相对清楚、不过度追求围度，并且能进入日常生活**。
把它往下抽一层，就变成一套可以跨领域使用的个人能力框架：

> **建立完成目标所需的「最小充分能力」，让它清楚显形、低负担运行、并且长期维持。**
> 简称 MSC（Minimum Sufficient Capability）。

一句话反转：**薄肌不是弱，而是没有无效围度。**

它同时反对两个极端：**能力不足**（看起来很轻，实际做不成事）和**能力过载**（能力、工具与复杂度不断膨胀，维护成本反而吞掉结果）。

## 它为什么存在

它给一个普通人的第一课是**找回主动权**：外部世界的反馈又慢又不可控，而训练、饮食、睡眠能提供清晰的「行动 → 结果」闭环。先在一个可控的战场上拿回主动权，这种控制感会外溢到工作与创作。
（这是「可控反馈链」模型，属**本人主张**。注意：这是它赋予健身的**个人成长意义**，不是「练肌肉能解决一切」。）

### → 建议进 `meta/principles.md`（通用方法：薄肌化七步，属「项目推演」）

一次只改**一个主系统**（身体 / AI / 学习 / 职业 / 内容），其余只保底：

```text
选一个系统 → 定义一次真实发力 → 找到真肌肉 → 删掉一块系统脂肪
→ 设计结果线条 → 运行七天 → 更新版本
```

对应的可判定写法：**七天只验证一个主要假设，不边跑边装十个新补丁。**

## 五种系统体型（诊断用词，不是给人的标签）

| 体型 | 症状 | 第一动作 |
|---|---|---|
| 肌薄 | 工具与愿望很多，核心能力不足 | 只练一块真肌肉 |
| 脂包肌 | 有能力，但被流程与维护负担遮住 | 先删一个低价值负担 |
| 镜头肌 | 展示很强，稳定交付很弱 | 用无滤镜任务验货 |
| 过度增肌 | 能力很强，但维护成本失控 | 设停止规则 |
| 薄肌态 | 能完成目标、结果清楚、负担可控 | 保持循环 |

**只描述某个系统此刻的状态，不给人贴永久标签。**（同一个人可能身体是薄肌态、工作流却是脂包肌。）

## 定性公式（是检查表，不是评分器）

```text
薄肌态 ≈ （真肌肉 × 结果显形 × 可持续性 × 版本适配）
        ÷ （系统冗余 + 维护成本 + 展示泡沫）
```

分子任一项接近零，系统再轻也没用；分母持续上涨，能力再强也会被自己拖住。**不要计算虚假的小数。**

## 争议与未验证之处（注入时必须保留这个性质）

- 「薄肌」**不是正式的生理学或医学分类**，它是在一定肌肉量与体脂条件下形成的**审美—行动框架**。
- 上面所有**跨域用法（学习薄肌、职业薄肌、AI 薄肌）都是系统隐喻**，不是对人体或人格的评价。
- 「薄肌理论 2.0 / MSC」是**项目推演**，**不代表邵艾伦本人已经提出或认可**。
- 七天实验**不能替代**医疗、心理、法律、财务或不可逆的职业判断。
