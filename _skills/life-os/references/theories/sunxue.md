## 它是什么

一句话总纲：**财富自由 = 不需要为金钱做出价值观的妥协**（妥协的形式：付出时间／金钱／注意力／情感与尊严）。

作者把它当作一套**先换三观、再谈赚钱**的世界观工程：讲「怎么赚钱」是术，讲「你是谁、你为什么而活、怎么看世界」是道。全书的论证顺序恒为 **时代 → 三观 → 路线 → 执行**。

## 候选条目

### → 建议进 `meta/principles.md`（跨板块通用原则）

理论原话多半不可判定，下面已给**可判定化**的改法（注入时应与用户一起定稿）。

| 理论主张 | 可判定化写法 | 出处 |
|---|---|---|
| 财富自由 = 不为金钱做价值观的妥协 | 做一个决定前，能说清它让你为钱妥协了哪一项——时间／注意力／情感尊严 | 总纲 · 书 PART5 |
| 成年 = 自我选择并承担后果 | 主动做一个决定前，先写清「我选了什么、代价是什么、失败时我担什么」 | 命名框架 3.2 |
| 拒绝「自我感动式努力」，以结果与价值为导向 | 一件花了时间的努力，要能回答：它产出了什么对他人或市场有用的价值 | 公理 A4 · 书 PART4-1 |
| 关注增量，不被存量绑架 | 投入前先问：这是啃过去的老本，还是买未来的成长空间 | 命名框架 3.4 |
| 穷人思维＝单变量归因，富人思维＝承认多变量 | 解释自己的一次成败时，只写出一个原因就补到三个以上才算数 | 命名框架 3.5 |
| 叛逆是创新的起点，和解是巩固成果的艺术 | 挑战规则前先写清「挑战的是哪条」；拿到结果后再决定是否转为和解 | 命名框架 3.3 |
| 主动选择，而不是被默认路径推着走 | 对职业／城市／婚育的现状，能指出它是「我选的」还是「我默认接受的」 | 书 PART1 |
| 先行动、后完美 | 一个想法若在自定的 N 周内没变成可验证的最小动作，就承认它目前只是空想 | 书 PART3-5 · 3.9 |
| 用事实说服人，不用道理说服人；不与人争三观 | 想说服人时，先给出可检验的事实或十年后的结果，而不是讲道理 | 命名框架 3.11 |
| 不让任何一次「归零」发生 | 任何决策前，指出它最坏情况是否会清空既有积累 | 命名框架 3.10 |
| 稳定是伪命题，不把安全感押在单一体制或岗位上 | 能指出自己当下安全感的具体来源，且不止一个 | 命名框架 3.9 |

### → 建议进 `career/goals.md` 与 `knowledge/goals.md`

- **财富流向「规则制定领域」，不流向「规则既定领域」**：择业进规则未定的新领域／新公司，而非既定的大机构。[3.13 规律一]
- **上升通道是非线性的**：判断一条路要看它有没有后期爆发的抛物线形态，而不是只看眼前斜率。[3.13 规律二]
- **原始积累四件套**：复利（纵向，最怕大额亏损）· 1% 定律（横向，别留短板）· 一万小时刻意练习（须有反馈与复盘）· 杠杆／溢出（一件事能衍生出多件事）。[3.10]
- **把新领域当增量空间**，用「降维」视角从传统行业跨进去。[3.14]
- 20–40 岁投在创造与自我提升上；把「先让自己变得更好」当作一切机会的前置条件。[书 PART4-2、3.7]

### → 建议进 `relations/principles.md` 与 `relations/goals.md`

家人是财富流失的两大主因之一，所以「边界」是**防御**，不是冷漠。

- **三层边界**：夫妻之间 · 父母子女之间 · 亲戚之间——**越亲密越要划界**。[3.11]
- **不做兜底关系**：无条件互相兜底 → 落差 → 撕裂。[3.11]
- **不借钱给家人**，改为把专业的事交给专业机构。[3.11]
- **配偶是唯一可以自己选的家人**：先想「怎么找」比想「怎么处」更重要；看三观是否契合 + 有没有好的分歧决策流程。[3.7]
- **进入前先想退出**（「合伙之前先散伙」）：没想清怎么退出的进入，是不严肃的进入。[3.7]
- **反物化**：衡量伴侣用「职业能力发展曲线」，而不是性别／外貌／年龄／国籍。[3.7]
- **与家人不争论、不说服**：完整表达立场即可，用事实（十年后的差距）说话。[3.11]

### → 建议进 `mind/principles.md`

- **不确定性的世界观**：稳定是伪命题，「稳定就是最大的不稳定」。[3.9]
- **MVP 思维**：产品与路径是演化出来的，不是一次设计出来的。[3.9]
- **正收益系统叠加**：单次结果随机、长期期望为正——把「城市 × 行业 × 时点」的正确选择叠加起来。[3.9]
- 不把安全感押在任何单一体制、岗位或关系上。[3.9]

### → 建议进 `meta/profile.md`

- 「认为自己在使用孙学这套框架」——这是一句**取向声明**，不是可测量的事实。

## 它给的执行方法（落成流程，不是原则）

- 用**未来视角**给当下的选择做体检：三年后回看，这个决定还成立吗？[书 PART2]
- **选长雪道**：一条路值不值得长期投，看它能不能持续增长至少十年。[3.10]
- 把注意力、个人品牌、信誉当作「全方位的资源吸附能力」，而不只是钱。[3.10 经营心态、3.15]
- 主动脱离默认路径（不默认找「稳定工作」、不默认「到点结婚买房买车」），以保住机动性。[书 PART1-3、PART4-3、3.6 三不主义]

## 争议与未验证之处（据源件「批判性备注」）

- **幸存者偏差**：整套框架建立在作者本人的成功之上，且其财富高度依赖特定时点的资产投机；「三观 → 财富自由」是**事后归因**。
- **可证伪性弱**：「好三观必然走向财富自由，只是时间早晚」属信仰，不是规律。
- **高风险断言**：书中涉及政治、历史、性别的判断是**特定立场**，与学术共识有距离。**引用时一律标注为「孙宇晨 2017 年观点」，而非「事实」。**
- 本书写于作者 26–27 岁，属**早期观点**；作者后来的公众争议与本包内容无关，本包只取可判定的认知方法。
