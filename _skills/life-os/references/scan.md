# 可选「只读扫盘」启动步

访谈开始前的一个**可选**捷径：经用户同意后，agent **只读**地扫一遍本机常见的 AI 目录与项目说明文件，把能看出来的东西提炼成「候选画像」，用户逐条确认后就不必再口述。**默认不做。**

位置：`SKILL.md` 的阶段 **0.6**（开场与理论包之后、基本盘之前），这样它的结论能直接省掉阶段 1 的一部分提问。

## 一、怎么问（一句话，不要推销）

> 要不要我先**只读**扫一遍你机器上常见的 AI 目录和项目说明文件，把已经能看出来的东西提炼成一份「候选画像」？你逐条确认后，就不用再口述这些了。**不想扫也行，直接跳过。**

- **默认不做。** 用户拒绝就**整段跳过**——不追问、不劝、不换个说法再问一次。
- 扫之前先把**要看哪些目录**说清楚（范围透明），用户可以只同意其中一部分。

## 二、白名单（只读这些）

- **AI 客户端与 CLI 的规则 / 记忆文本**：`AGENTS.md`、`CLAUDE.md`、`CODEBUDDY.md`、`GEMINI.md`、`.cursorrules`、`.github/copilot-instructions.md`，以及 `~/.codex/`、`~/.claude/`、`~/.gemini/`、`~/.hermes/`、`~/.workbuddy/` 下的 `MEMORY.md` 一类**记忆与规则**文本。
  （这类目录常带着用户自己的长期记忆，最能用来自动补全画像——比如 `hermes` 那类带记忆的 agent 目录。）
- **本机项目的说明性文本**：各个项目 / 仓库根目录的 `README.md`、`AGENTS.md`、`docs/` 里的项目介绍。
- **只看这些说明性文本**，不通读整个文件树。

## 三、禁止项（一律不读、不写、不入包）

- **凭据与密钥**：`mcp.json`、`.env`、任何 `credentials*` / `*token*` / `*.pem` / `*.key`、SSH 密钥、密码库、cookie 文件——**不打开、不复制**。
- **他人资料**：通讯录、邮件正文、聊天记录、家人朋友写给用户的私事。
- **与访谈无关的个人文件**：照片、财务单据、合同、病历——不主动去找；目录里遇到就跳过。
- 不打开二进制文件或大文件。

## 四、只读纪律（硬约束）

- **不修改任何文件**（包括不新建、不改名、不移动）。
- **不外发、不发起任何会把内容带出本机的请求**（依据 `docs/adr/0005`）。
- 扫到的东西**只在本机内使用**；原始文本**不复制进包**。

## 五、提炼与确认

1. 把扫到的内容**只提炼成结论**（例如「常驻某城市」「在做某方向的工作」「有一个长期项目叫 X」），**不粘贴原文**。
2. **逐条念给用户**，让他确认 / 修改 / 丢弃。**只有确认过的才落盘。**
3. 落盘位置按内容性质定：跨板块的稳定事实 → `meta/profile.md`；某板块内的 → 该板块 `profile.md`。义务与画像代录相同：**整体复述本人确认**，并在文件末尾注明「**由 agent 代录本人口述**」（依据 `docs/adr/0015`）。

## 六、扫到敏感内容时

**他人私事**或**凭据密钥**类内容，一律**不写、不入包**，只提示用户：「在某处看到疑似凭据 / 他人的私人内容，建议你自己确认怎么处置。」不要把内容本身复述出来。

## 七、两条边界

- **拒绝扫盘的用户，访谈流程与耗时不受影响。** 扫盘只是省力的可选捷径，不是必经步骤；用户不扫，阶段 1 照常口头问。
- **与「首次访谈」判定一致**：包**已有板块目录**（已经访谈过）时**不重复扫**——那时也没有可写入的窗口（见 `docs/adr/0015`）。
- **载体读不到本机文件时**（例如用户只是把 `SKILL.md` 粘进对话框），跳过并说明跳过了。
