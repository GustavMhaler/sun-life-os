# 落盘规范与检查清单（展开版）

## 一、生成什么

访谈结束后，包根下应新增：

```
meta/profile.md          ← 覆盖，写入他的真实信息（访谈期代录，见下）
meta/principles.md       ← 覆盖，写入他的通用原则
body/  mind/  career/    ← 只生成他激活的那几个
  ├── profile.md
  ├── goals.md
  ├── principles.md
  ├── state.md
  └── log/2026-10.md     ← 当月那一份
viewer.html              ← 重写数据岛
```

**写画像的依据**：`profile.md` 平时 agent 只读，但**访谈期是正式例外**——包尚未访谈过且正在跑访谈流程时，agent 可代录本人口述（落盘前整体复述并经本人确认，写入后文件末尾注明「由 agent 代录本人口述」）；访谈结束立即回到只读。所以上面这两个 `profile.md`（`meta/` 的与各板块的）在首次访谈时**允许覆盖**，不与「画像只有人能写」冲突。依据见 `docs/adr/0015`。

**不要动**：`AGENTS.md`、`README.md`、`GEMINI.md`、`.gemini/`、`_template/`、`_skills/`、`CONTEXT.md`、`docs/`。

## 二、frontmatter 固定三项

```yaml
---
domain: body
type: principles
updated: 2026-10-13
---
```

`type` 取值只有五个：`profile` `goals` `principles` `state` `log`。

## 四、填写要点

- `profile.md`：只写**稳定**的事实。会变的东西放 `state.md`。这个文件平时只有人能改；**首次访谈期是唯一例外**，agent 代录（义务见上节）。
- `goals.md`：每个目标都要有**期限**和**判定标准**。没有期限的目标不算目标，先在收尾时补上或标待定。
- `principles.md`：一条一行，每条可判定。这是整份访谈最值钱的部分，宁可少而准。
- `state.md`：只写**此刻**的样子，写成快照而不是历史。以后被覆盖时要在文件末尾追加一行变更记录。
- `log/YYYY-MM.md`：**首次生成时是空的**，只有表头。访谈的问答不要塞进来。

## 五、访谈问答为什么不能当流水

流水是**写后不改**的记录，价值在于忠实。如果把访谈内容塞进去，第一次「更新」就会有人想去改它，这个约定当场就废了。访谈产出的是判断依据（原则、目标、状态），流水留给以后真实的每一天。

## 六、待定项怎么处理

所有答不上来、被跳过的，统一写进 `meta/profile.md` 末尾：

```md
## 待定

- 价值排序（第 7 题）：他说"没想过"，未落定
- money 板块的存款目标：暂时跳过
```

**不要**把待定项散落到各板块里——它们会变成读文件时的噪音，而且没人会想起来补。

## 七、收尾时说什么

落盘之后**不是「三句话打发」，而是给一段「收尾指引」**——它同时干两件事：给这次访谈画句号，把用户领进日常使用。**完整话术在 `SKILL.md` 阶段 5（那里自包含，因为有些用户只拿到那一份）**；这里只记要点与依据，改话术时两边一起改：

| 要讲什么 | 依据 |
|---|---|
| 先说访谈到此结束、系统已经建好 | 对话形态在这里切换：从「它问你」变成「你使唤它」 |
| 生成了哪几个板块、每板块含哪五类记录 | 本节「一、生成什么」与 `_template/` |
| 理论包落了哪几套条目 | `references/theories/adaptation.md` |
| 待定项逐条列出 | `meta/profile.md` 的 `## 待定`；**没有待定项就整段不讲**，不要凑 |
| 4–6 条「你对它说 → 它会做」，每条配一句具体的话 | 必须与 `AGENTS.md` 写权限节一致：问建议＝只读；记一笔＝追加流水；改状态＝留变更记录；改目标／原则＝先确认；画像只有人能写 |
| 常用口令 | 只有「刷新查看器」「记一笔」。本次要**新增口令**，必须同时写进 `README.md` 与 `guide/quickstart.md`，否则不许在收尾里提 |
| 边界：不联网、不用注册、**不会主动提醒**、备份＝复制整个文件夹 | `docs/adr/0005`、`README.md` |
| 换了 agent／新开会话怎么接上 | 设成工作目录 + 让它读 `AGENTS.md`（`guide/quickstart.md` 第二步） |

**三条禁令**：不吹能力（不得承诺云同步／跨设备／定时提醒／账号／使用统计）；不重复其它环节（理论包性质、扫盘白名单、追问规则、板块范围一律指过去）；不靠堆篇幅——**用具体例子换掉笼统**，整段控制在一屏内（约 300–400 字）。
