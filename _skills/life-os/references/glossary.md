# 理论术语表（一句话 + 一个例子）

**用途**：访谈里呈现任何理论条目时，术语一律用「一句人话 + 一个具体例子」讲清，禁止只丢名词。本表就是现场查阅的入口——`SKILL.md` 阶段 0.5 会指向它。

**规则**：

- **术语的释义只在本表给**（一句人话 + 一个例子）。各理论包里的表格给的是**可判定化写法与落点**，不是释义；两者不得互相矛盾。
- 本表**不放条目落点**——落点表在 `theories/adaptation.md`。
- **读不到本表、又读不到对应理论包时，不得编造释义**：请用户提供，或跳过该环节并说明跳过了（编造一个术语释义比不做这一步危险得多）。
- 这些术语**只是某套框架里的用词**：孙学是孙宇晨本人的主张；薄肌里「跨域薄肌化」相关的是**项目推演，不是邵艾伦本人提出的**；黄毛来自**第三方网络材料**。讲给用户听时要一并说清是谁说的（依据 `docs/adr/0014`）。

## 孙学（孙宇晨 · 本人主张）

**原始积累四件套**
泛指攒下第一笔本钱（不只是钱，也包括能力与声誉）的四个动作：复利（纵向）、1% 定律（横向）、一万小时（练法）、杠杆溢出（放大）。它们是一组，不是四选一。
例：一个人既让钱滚起来、又不留明显短板、又在专业上做刻意练习、还把一份努力变成几份产出——四件都在做，积累速度才快。

**复利**
今天的结果会成为明天的基础，收益再产生收益，所以差距是**指数级**的，不是线性叠加的。
例：同样起步，年化差一点点，几十年后的差距是数量级的（源件给的量级是 5% 与 30% 在 50 年后的差距以「倍」计的系数）。
注意：复利**最怕大额亏损**——一次亏光就归零，前面全白搭。

**1% 定律**
在**多个维度上各比平均水平好一点点**，合起来不是「加 5%」，而是在排名上大约前进 **20%**。重点在「不留短板」。
例：高考五科每科各多考几分，总分排名就能跳一大截；英国自行车队把每个细小环节都改进约 1%，几年后拿到奥运金牌（源件的「边际增益」案例）。

**一万小时**
不是「练够一万小时」，而是「练够一万小时的**刻意练习**」——跳出舒适区、难度贴着当前水平、把动作拆开系统练，**并且有反馈和复盘**。
例：踢了一万小时野球不会成为巨星，因为没人给你反馈；打了几千盘游戏还在低段位，也是同一个原因。

**杠杆 / 溢出效应**
做一件有附加值的事，它能**衍生出第二件、第三件**。
例：把工作里踩过的坑写成公开文章，别人因文章找到你合作——一份时间投入，换回多份回报。

**正收益叠加**
单次结果有随机性，但把几个**长期期望为正**的选择叠在一起，长期就是往上走。
例：城市选对 + 行业选对 + 在低谷进入，三项都占，结果不是「好一点」，而是好很多。

## 薄肌（邵艾伦本人主张；跨域部分为项目推演）

> 本组里的训练与饮食描述**不是医嘱**。用户有基础病、旧伤或正在服药时，须提示先咨询医生。这些词用于分析计划与能力结构，**不用来评价身体、体重或人的价值**。

**真肌肉**
能**稳定完成任务**的核心能力，不是「知道过」、也不是「看起来会」。
例：一个概念，你不看原文也能讲给一个具体的人听，并用它解决一个真实问题——这才算长上了。

**系统脂肪**
持续占资源、却很少改变结果的负担。
例：收藏了一堆课程从没打开；为了显得专业而加出来的术语和层级；一个没人看的周报——都是。

**结果线条**
外界**能看见、能验收**的成果。有能力但别人完全看不见，等于没有结果线条。
例：不是「我正在学数据分析」，而是「我交出了一份能用的分析报告」。

**代谢循环**
系统得能一圈一圈转：**做最小训练 → 产生可见结果 → 收反馈 → 恢复与删减 → 更新下一版**。不能重复的，不叫系统，叫冲刺。
例：每周练、每周看数据、每周调一点，能一直转下去；而不是猛练一个月然后停掉。

**版本环境**
能力的**最优形态会随时代、角色、目标和约束变化**，所以要问「此刻真正需要什么」。
例：三年前帮你升职的技能，今天可能只是维护负担；换了岗位，答案就得换。

**薄肌态**
能完成目标、结果清楚、负担可控、可以长期维持的状态。
例：一个流程跑得顺，你也不必天天救火。

## 黄毛（第三方文档）

**配得感**
不需要先证明什么，也**敢去要**。它不靠光环支撑。
例：去申请一个你没完全够格的机会时，先不问「我配吗」，而是问「这是不是我想要的」。

**优越感**
靠后天叠出来的**光环**（头衔、收入、资历）来确认自己比别人强。
例：开口先报头衔。

**配得感 ≠ 优越感（两者区别）**
优越感是「**我比你强，所以我有资格**」；配得感是「**我不需要跟谁比，也照样敢要**」。配得感**不等于**「我不可能错」——它只表示不自证，不表示没有判断力。

**低自尊（本框架语境）**
这里的「低自尊」指**没有 ego、不在乎面子**，**不是**临床意义上的自我评价低——别误读成心理问题。

**不解释法则**
解释就等于把自己放到低位。被质疑时先不解释，隔 24 小时再决定要不要补充说明。
例：被人当众挑刺，先不回，第二天再看要不要回应——多数时候不用了。

**我行我素**
不为合群放弃自己认定的事。但**变更可以基于新事实**——坚持之前要能说出「什么情况下我会认错」，说不出来那是固执，不是坚持。
