# 理论包多源与归属层级：不得混用来源，不得把推演当人物原话

本 ADR 补充而非替代 ADR-0012 与 ADR-0013。前两者分别定了「理论包是否注入」的机制与「随包分发内容的三条硬红线」，本 ADR 定的是「每套包的条目怎么标注来源、来源之间怎么区隔」。

起因是三套可选理论包经核实后，来源各不相同，且与最初假设不同。孙学来自孙宇晨的《这世界既残酷也温柔》（九州出版社 2017）与音频课《财富自由革命之路》（2016 喜马拉雅）；薄肌来自邵艾伦本人的开源项目「薄肌理论 2.0」（github.com/XiaoSiKe/shao-alan-operating-system），不是孙宇晨的——它自己就把内容分两级，「本人主张」（身体薄肌原型 ＋ 六个行动模型）与「项目推演」（MSC、五种系统体型、薄肌化七步、AI 模块，明确不是本人提出）；黄毛来自第三方材料——概念源头是一条 X 帖《关于黄毛统治世界》，操作化拆解在第三方网络技能文档《黄毛决胜法 — Alpha Game Mastery》（github.com/0xcii/alpha-game-mastery），与孙宇晨、邵艾伦两位受访者都无关。三套包的出处彼此独立，最初把它们笼统当成「受访者主张」的假设已被推翻。

据此定死两条：

其一，**每个理论包的条目必须标注归属层级**。层级至少三级——**本人主张**（可追溯到本人公开材料）、**项目推演**（他人基于本人模型做的跨域推演，不是本人提出）、**第三方文档**（与人物无关的独立材料）。每条落盘条目都要带这一级，做到「是谁说的」一眼可辨。

其二，**不得张冠李戴**。尤其不得把「薄肌」写成孙宇晨的主张，也不得把「黄毛」写成两位受访者的主张。落盘时把项目推演或第三方文档写成人物原话，与把一套理论的来源安到另一套理论的受访者头上，同样属于违规。

被标注为「项目推演」的内容，注入时须同时说明「这不是本人提出的」，让读到的人不会误以为是受访者本人的话。理论包作者与注入 agent 都对该标注负责：漏标或错标层级，等于把别人的推演塞进了人物的嘴里。
