# 每条记录必须唯一归属一个板块，跨板块只允许单向引用

真实数据里总有跨板块的东西：「晚上 11 点前睡觉」算身体还是心智？「不接低价项目」算事业还是财务？有三种处理方式：复制到多个板块、设一个顶层通用区放全部跨界内容、或者强制唯一归属、跨界关系用引用表达。

选第三种。**复制是 ADR-0001 反对的副本问题在条目层面的重演**——同一个判断存在两处，改一处漏一处，agent 会读到互相矛盾的两条原则，而这恰好是最伤信任的失败模式。

归属判据：**这条内容影响哪个板块的 agent 决策最多，就归哪个板块**，其余板块用引用指过去。为保证 agent 不陷入重复阅读，引用**必须单向**（A 引用 B），不得互相引用成环。

唯一例外：确实横跨全部板块、且极度稳定的少数几条——例如「我的核心价值排序」「我的决策风格」——放顶层 `meta/`。硬塞进某个板块会让其他板块的 agent 根本读不到它。
