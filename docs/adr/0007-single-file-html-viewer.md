# 交付物包含一个单文件本地 HTML 查看器

只给用户一个装满 Markdown 的文件夹是不够的：绝大多数人不会去翻这些文件，于是他们永远无法确认「AI 记住的我到底对不对」。信任需要一个落点，所以交付物是两份——给 agent 读的 Markdown 文件包，和给人看的单文件 HTML 查看器：离线、双击打开、内容已嵌在里面、能把全文一键复制给任何 AI。它同时是让整个压缩包显得可信的那个界面。

明确的非目标：**不做编辑器**（浏览器里只读和导出很好做，而「改了就存」需要目录授权 API，手机上基本不可用，收益配不上复杂度）；**不做线上版**（与 ADR-0005 直接冲突）。查看器的第一版只做呈现与导出。
