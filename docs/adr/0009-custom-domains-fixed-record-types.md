# 板块可自定义，记录类型不可

与 ADR-0003 配套的边界划分：**板块是内容边界（开放），记录类型是结构契约（封闭）**。

模板预置 8 个板块，实例中由 agent 按访谈结果推荐 3–5 个激活、并说明推荐理由（理由必须给出，否则用户不知道自己关掉了什么），用户可增删。同时允许用户自定义板块（「养狗管理」「备考管理」这类）。但自定义板块必须套用五类记录的模板，不得自创文档类别。

理由是这两件事的性质不同：板块的数量与命名因人而异，是真实差异，封死它会让系统对多数人不适用；而结构一旦各自为政，模板就无法可靠地生成和验证实例，跨 agent 的读取约定也无从写起——那是系统赖以成立的基础。
