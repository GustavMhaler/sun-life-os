# 理论包内容红线：政治敏感、物化表述、投资标的不得进包

本 ADR 补充而非替代 ADR-0012。ADR-0012 定的是「理论包是否注入」的机制，本 ADR 定的是「随包分发的内容本身有什么不能带」。

包会作为压缩包分发到任意用户手里——他可能在任何地区、任何设备上解压，也可能把整包转给第三人。因此理论包随包分发的内容有三条硬红线，碰到一律不进包，只留在项目存档里：

1. **政治敏感内容。** 对体制、国民性、教科书、财产制度等的批评与断言，以及一切会被解读为政治立场站队或敏感议题表态的措辞。
2. **外貌与性别物化表述。** 把人的外貌、性别当作可评估、可交易、可优化的工具性对象的表述，以及以「吸引力／后代质量」为动机的择偶或人生建议。
3. **投资标的／具体金额／变现路径／加杠杆操作。** 个股、Crypto 标的、具体金额与仓位、变现方式、杠杆或配资操作。

前两类是本次新增的约束，此前只覆盖了第三类。第三条原本散见于 ADR-0012 与 `adaptation.md` 的排除清单，这里一并收口为长期红线，对所有理论包统一适用。

红线裁剪的是「随包分发」的内容，不是「给人看」的材料。被红线拦下的完整原文保存在项目存档（`.workbuddy/research/`），需要回查时仍在。一个包要查证某条主张的完整上下文，回项目存档即可，不必为了合规把原文塞回交付物。

被红线过滤过的源件，文件开头必须有「阅读须知」，写明它是过滤版、过滤的依据是本 ADR。这样读源件的人知道它经过了裁剪、也知道为什么裁剪，不会被一份缺胳膊少腿的文本误导。

这不是价值审查。价值观主张——例如利己主义、自由意志主义——保留并标注立场，由用户自行判断。红线的对象不是「观点」，而是「会造成分发风险」或「把判据引向对外貌与他人工具化」的内容。换句话说，删的是风险与物化，不删立场。
