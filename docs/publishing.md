# 发布前检查（维护者用）

这个包会被**公开分发**（压缩包、GitHub、网盘……）。分发对象是任意陌生人，所以发布前必须逐项确认下面这些。

## 一条硬规矩

**交付目录与实例目录必须分开。**

- **交付目录**：只放空骨架，可以公开。
- **实例目录**：跑过一次访谈之后，它里面就有某个真人的全部档案——**永不公开**。

**同一个目录既跑访谈又准备发布，是最容易出事的做法。** 想在自己的机器上试访谈，先复制一份出去再试：

```bash
cp -r <交付目录> /tmp/试访谈
```

## 发布前逐项确认

- [ ] 根目录下**没有任何板块目录**（`body/` `mind/` `career/` `knowledge/` `money/` `relations/` `life/` `create/`）
- [ ] `meta/profile.md`、`meta/principles.md` 是**空模板**，末尾 `## 待定` 为空
- [ ] `viewer.html` 的数据岛是**空骨架**，没有被真实数据覆盖过
- [ ] 全目录检索一组真实隐私词（姓名、常住地、宠物名、生日、家人称谓），**零命中**
- [ ] 文档与模板里的**示例不含真实地名与人名**——地名一律写成 `<城市>` 这类占位符
- [ ] 没有 `.workbuddy/`、`.scratch/`、`*.zip` 混进包
- [ ] `docs/adr/` 里没有夹带个人化的决策记录

## 怎么扫

```bash
# 把词换成你自己要防的；至少包含姓名、城市、宠物名、生日
for p in "<姓名>" "<城市>" "<宠物名>" "<生日>"; do
  printf '%-12s %s\n' "$p" "$(grep -rl "$p" . --exclude-dir=.git 2>/dev/null | wc -l)"
done
```

全都应为 `0`。

## 打包

```bash
zip -r -q <包名>.zip . -x '.workbuddy/*' -x '.git/*' -x '.scratch/*' -x '*.zip'
```

`.gitignore` 已排除 `.workbuddy/`、`.scratch/`、`*.zip`；`git init` 之后它们不会被提交，但**打包时仍要显式排除**——别指望两个机制自动互通。
