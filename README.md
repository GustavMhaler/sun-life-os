# Life OS

**这是你的。** 一个装满 Markdown 文件的文件夹，装着关于你这个人的一切——身体、心智、事业、学识、财务、关系、日常、创作。

它真正的特点不是给人看的，是给 **AI agent** 读的：任何能读写本地文件的 agent，读完就能替你记事、替你判断。

---

## 它到底是什么

不是 App，不是网站，不是账号——**就是一个文件夹**：一堆纯文本 `.md` 文件，外加一个离线可看的 `viewer.html`。

没有注册、没有登录、没有服务器。内容只在你硬盘上；谁能读它，取决于谁拿到了这个文件夹。

## 它管你人生的八块

| 板块 | 目录 | 范围 |
|---|---|---|
| 身体 | `body/` | **身心硬件的状态与维护**——训练、摄入、睡眠、体征、伤病与恢复 |
| 心智 | `mind/` | **内在状态与自我认定**——情绪、压力、注意力、动力，以及你怎么看自己 |
| 事业 | `career/` | **你靠什么谋生，以及工作怎么组织**——职业身份与路径、工作协作、项目管理 |
| 学识 | `knowledge/` | **学习与真本事**——读什么、学什么、怎么把输入变成能用的能力 |
| 财务 | `money/` | **钱本身**——收入结构、支出、储蓄、投资纪律与财务安全线 |
| 关系 | `relations/` | **一切长期人际关系**——家人、伴侣、亲友、同事 |
| 生活运营 | `life/` | **日常怎么转起来**——日程、家务、通勤、物品与文件的打理、拖着没做的杂事 |
| 创造 | `create/` | **你产出的作品**——写作、视频、项目、博客、代码 |

三点要知道：

- **只生成你真正要管的那几块。** 访谈时你自己挑；没选的板块不会生成，不会给你留一堆空目录。以后想加，说一声就行。
- **边界是定死的，不是凭感觉分的。** 上面八句与 `_skills/life-os/references/domains.md` 逐字一致（那里是定义处，改一处要一起改）。重叠处有明确分流规则：同一个同事，私人往来归**关系**、工作任务归**事业**；同一份工资，谈职业发展归**事业**、谈收支结构归**财务**。
- **一件事只归一个板块。** 别的板块需要它，就写相对路径引过去，绝不抄第二份——所以你的档案不会出现「两个地方说法不一样」。

## 每个板块里放什么：五类固定记录

每个激活的板块，都固定装这五类文件（结构契约的权威定义在 `AGENTS.md`，下表是给人看的摘要）：

| 文件 | 装什么 | 谁可以写 |
|---|---|---|
| `profile.md` | 稳定的、几乎不变的事实 | **只有你能写** |
| `goals.md` | 有期限、能判定是否达成的追求 | 你确认后，agent 才能改 |
| `principles.md` | 硬约束与偏好判据（**最重要的一类**） | 你确认后，agent 才能改 |
| `state.md` | 当前快照，反复被覆盖 | agent 可改，**每次必须留一行变更记录** |
| `log/YYYY-MM.md` | 追加式、写后不改的流水 | agent 唯一默认可写 |

**整套系统的可信度就来自这张表**：

- **越稳定的东西越难写。** 关于你的事实（画像）永远只有你能改。唯一例外在访谈期间——它把你的口述代录进去，并在文件末尾注明「由 agent 代录本人口述」，访谈一结束就恢复只读（见 `docs/adr/0015`）。
- **判据必须你点头。** `principles.md` 是它给你建议时用的尺子；改尺子，等于换掉系统的判断基准。
- **状态可以变，但要留痕。** `state.md` 会被反复覆盖，所以每改一次就追加一行「什么时候、改了什么、依据是什么」。
- **流水是时间轴。** `log/` 只追加、不回头改——这是你唯一能放心让它随便写的地方。

## 它怎么工作：三句话原理

1. **唯一真相源是一个文件夹。** 你、agent、`viewer.html` 读的是同一批文件。没有数据库、没有云端副本，也就不存在「两边对不上」。
2. **能力来自写权限的不对称。** 事实只有人能写、判据要人确认、状态改动留痕、流水随便追加——它的可信不是靠提示词求来的，是靠这条权限分层守住的。
3. **它靠访谈长出来，不靠你填表。** 空骨架对所有人都一样；跑完一次访谈（那是一次对话），它才变成你的。所以两个人的系统内容完全不同，结构契约却一致。

还有一个刻意的取舍：**它不联网、无账号、无服务器。** 换来的是内容永不出本机；代价是**它不会主动提醒你**——没有推送通道，要用就得你开口。

## 你拿它干什么

| 你说 | 它会做 | 动不动文件 |
|---|---|---|
| 「我这两周睡得很差，身体这块怎么调」 | 一起读你身体板块的画像、状态、原则，给出**贴合你**的判断，而不是通用建议 | **只读** |
| 「这个副业要不要做」 | 同时读事业、财务、原则、关系，用**你自己的判据**回答你 | **只读** |
| 「记一笔：今天……」 | 往当月流水追加一行 | 追加 |
| 「最近换工作了，事业那块更新一下」 | 更新状态，并留一行变更记录 | 改状态 |
| 「我这条原则改成……」 | 先说清它会波及哪些判断，你确认后才落盘 | 需你确认 |
| 「刷新查看器」 | 更新 `viewer.html`，你就能看到最新全貌 | 改查看器 |
| 「换个 agent 接手」 | 新 agent 设成工作目录、读 `AGENTS.md`，立刻接上，不用重新访谈 | **只读** |

**它最值钱的用法不是「记录」，而是「对照」。** 它手里同时握着你的原则、现状和已定目标——所以你问「这件事要不要做」，它拿你自己的尺子量给你看，而不是拿一套放之四海的建议。这是它跟普通聊天 AI 最不一样的地方。

## 三步开始

**① 装一个合格的 agent。**
门槛只有一条：**能读写本地文件**（能读目录、能把结果写回磁盘），不是只能上传单个文件聊天的那种。候选清单见 [`guide/quickstart.md`](guide/quickstart.md)。

**② 把这个文件夹设成 agent 的工作目录。**
这是新手最容易卡住的一步，`guide/quickstart.md` 里有各家 agent 的具体做法。做对这一步，包内所有相对路径才能正确解析。

**③ 让它读 `AGENTS.md`。**
多数 agent 会自动读。不会的那几个，把这句话原样发给它：

> 请读 `AGENTS.md`，并严格按它的规则工作。

然后它会开始**访谈**你——那是一次对话，不是填表。访谈结束时，这个空骨架会长成属于你自己的系统。

## 访谈开始时会先问你两件事

**一、要不要注入几套可选理论包。** 都是一些现成的人生框架（比如「孙学」的认知方法、「薄肌」的「最小充分能力」框架、「黄毛」的自我姿态与边界）。**这几套的来源各不相同，它会如实告诉你每一套是谁的**，不会混着说。**默认不注入，你也可以一套都不要。** 就算选了，每一条也会先念给你听、你点头了才写进档案，并且带着来源标注（含**它是谁说的**）——想扔，随时说一声就能整套摘掉。

**二、要不要让它先只读扫一遍你的电脑。** 它可以**只读**扫一遍机器上常见的 AI 目录（比如那些带自己记忆的 agent 目录）和项目说明文件，把已能看出来的东西提炼成一份「候选画像」，你逐条确认后就不必再口述。**默认不做。不想扫就直接跳过，访谈照常进行，一步也不少。** 它只读、不外发；扫到凭据或别人的私人内容，一律不写、只提醒你自己处置。

## 访谈结束之后

落盘完成后，它会给你一段**收尾指引**：这次生成了哪几块、有哪些还**待定**、以后可以怎么用它——每条都配一句**能直接说出口的话**，不是产品介绍。

常用口令记这两个就够：

- **「刷新查看器」**——让 `viewer.html` 显示最新内容（也可以直接双击这个文件看）。
- **「记一笔」**——往当月流水追加一条记录。

**它不会主动提醒你**（没有账号、没有服务器，也就没有推送）——要用的时候，得你开口。

## 文件都在哪

| 路径 | 是什么 |
|---|---|
| `AGENTS.md` | agent 的规则书，**唯一真身**。别改 |
| `README.md` | 你正在读的这一份 |
| `viewer.html` | 给人看的界面，离线可用 |
| `guide/` | 上手文档：`quickstart.md` 小白版 · `advanced.md` 进阶版 |
| `meta/` | 跨板块的稳定信息与通用原则 |
| `_template/` | 五类记录的空模板，作样板用。**别动** |
| `_skills/` | 访谈脑。**别动** |
| `body/` `mind/` `career/` … | 访谈之后才会出现，是你自己的数据 |

下划线开头的两个目录（`_template/`、`_skills/`）你不需要碰。

## 关于隐私

这个包**不联网、不用注册、不经过任何服务器**。所有内容只待在你这台机器上。

也正因为如此，它没有账号、没有云同步、也没有人会主动提醒你——**备份就是把整个文件夹复制一份**。
