# 快速上手（给没接触过 AI agent 的你）

Life OS 是一份放在你电脑上的个人档案。它本身不会帮你做什么，真正干活的是**能读写你电脑文件的 AI agent**——你把这个文件夹交给它，它读完规则后就能替你做判断。

下面三步，跟着做就行。

---

## 第一步：装一个合格的 agent

你需要一个**合格载体**：一个能读写你本地文件的 AI agent。

国内拿来就能用的：

- **WorkBuddy**（腾讯，桌面版）——右键就能打开本地文件并写回，中文界面。
- **豆包电脑版**的「办公任务」模式——授权文件夹后能读能写，免费。
- **智谱清言** PC 客户端——可以挂载本地文件夹做跨文件分析。
- **Trae** 国内版——免费，Agent 能直接读写项目文件。

手机上的话，普通 AI 对话 App（豆包 / Kimi / 元宝 / 通义 的手机版）**都不合格**——它们只能让你上传单个文件聊天。手机上目前要 **OpenMinis** 这一类自带文件系统的 agent 才算合格。

> Codex、Gemini CLI、Claude Code 这些海外工具在大陆需要额外的网络条件，不适合新手起步。等你熟了再说。

判断合格的标准只有一条：**它能把生成的内容写回你的硬盘，而不是只在聊天框里跟你说话。**

纯网页聊天框、只能单次上传一个文件、没法把产出保存到磁盘的，都不算合格载体——本系统不为这类工具提供降级方案。

> 如果你不确定某个工具合不合格，看它能不能「在指定文件夹里新建/修改 .md 文件」。能，就合格。

---

## 第二步：把这个文件夹设成它的「工作目录」

这一步是新手最容易卡住的，讲清楚。

**什么是工作目录**：agent 干活时，有一个「当前所在文件夹」。它读文件、写文件，都默认在这个文件夹里找。你把工作目录指到 Life OS 这个文件夹，就等于告诉 agent：「你管的范围就是这里。」

**怎么设**（因工具而异，选你用的那个）：

- **WorkBuddy / Codex 等桌面版**：打开工具后，新建或打开对话时，选择「工作目录 / Working Directory」为本系统的文件夹（就是包含 `AGENTS.md` 的这个目录）。
- **命令行版**：启动前先 `cd` 进这个文件夹，再运行 agent；或在启动命令里指定目录参数。
- 记不住也没关系：只要 agent 启动后，你让它「读当前目录下的 AGENTS.md」，它自己通常在的目录就是工作目录。

确认方法：让 agent 列一下当前目录的文件，如果它列出 `AGENTS.md`、`_template/`、`guide/` 这些，说明设对了。

---

## 第三步：让 agent 读 `AGENTS.md`

工作目录设好后，直接对它说一句话：

> 请读 AGENTS.md，并严格按它的规则工作。

agent 读完这份入口文件，就知道本系统的全部规矩（哪些文件它能写、哪些只能你写、数据怎么组织）。之后你让它「开始访谈」，它就会用提问把你这套空的骨架长成你自己的实例。

> 访谈一开始，它会先问你一个问题：要不要注入几套**可选理论包**（现成的人生框架）。**默认不注入，你也可以一套都不要**；就算选了，每一条也要你点头才会写进档案。不想要就直说。
>
> 访谈里它还可能问你要不要**只读**扫一遍你的电脑（看那几个常见的 AI 目录和项目说明文件），用来少问几个已经知道的问题。**默认不做，拒绝就直接跳过**，不影响访谈。它只读、不外发，扫到凭据或别人的私事一律不写。

---

## 之后

访谈会产生真实数据，存在各个板块的 `profile.md` / `goals.md` / `principles.md` / `state.md` / `log/` 里。结束时它会给你一段**收尾指引**，说清这次生成了什么、有哪些还待定——以及下面这些能立刻上手的用法：

- **问建议**：把事说清楚就行（比如「我这两周睡得很差，身体这块怎么调」）。它会读你的档案给出**贴合你**的判断——这一步它只读，不改动任何文件。
- **记一笔**：说「记一笔：今天……」→ 它往当月流水追加一行。
- **改状态 / 改目标**：说清哪里变了。改状态它会留一行变更记录；改目标或原则它会**先跟你确认**再落盘（画像只有你自己能改）。
- **看结果**：双击 `viewer.html`，或对 agent 说「刷新查看器」；想让任意 AI 帮忙，点页面上的「复制全文」把内容贴给它即可。

另外三件事：不联网、不用注册，内容只在你机器上；**它不会主动提醒你**，得你开口；**备份就是把整个文件夹复制一份**。

以后换了 agent、或新开一个会话：把它设成工作目录，让它读 `AGENTS.md`（就是上面的第二步和第三步），它就能接着管你这套系统。

更细的多 agent 入口配置，见 `guide/advanced.md`。
